Run DB AutoRun on your own computer

This website runs on a server, so it can't reach a database on your computer. To use your local databases, run it on your PC (Windows or Mac) — no install, just one command:

npx dbautorun
  1. Windows: open the Start menu, type cmd, press Enter.  Mac: open Terminal (press Cmd+Space, type Terminal).
  2. Paste the command above and press Enter. The first run sets itself up automatically.
  3. Open the address it shows (http://localhost:5757) and choose "Local run".
